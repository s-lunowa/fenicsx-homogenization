# FEniCSx Homogenization

This repository contains FEniCSx implementations of Stokes and Darcy flow using
the non-conforming mixed BDM-DG and RT-DG elements (discrete divergence-free).

This software contains the implementation of the numerical simulations presented
in section 4 of the corresponding publication:  
L. Balazi, F. Holzberger, S.B. Lunowa, M.A. Peter, D. Peterseim, & B. Wohlmuth,
*Effective permeabilities for flow through anisotropic microscopic geometries*,
[arXiv:2512.04133](https://arxiv.org/abs/2512.04133) (2025).

The authors of this software are F. Holzberger and S.B. Lunowa.


## 1. Requirements

Ubuntu 24.04 with the following packages:

- fenicsx (version 0.9.0 or version 0.10.0)
- gmsh (version 4.9 or higher)
- python3-gmsh (version 4.9 or higher)
- Python libraries specified in `docker/requirements.txt`

To install these run the following command:  
```
sudo apt install fenicsx gmsh python3-gmsh
```
To set up Python, create and activate a virtual environment:
```
python3 -m venv pyhomogenization
source pyhomogenization/bin/activate
pip install --upgrade pip
pip install -r docker/requirements.txt
```

Alternatively you can run it from a docker container, which has access to this
directory. To create and start the container run:  
```
docker/build.sh
docker/run.sh
```
To enter the docker container run:  
```
docker/exec.sh
```


## 2. Mesh Generation

The mesh files (`.msh`) are based on `gmsh`.

The cube with cut-out cylinders can be generated from the geometry model with
the following command:  
```
gmsh -3 geometry/cube_cylinder.geo
```

The cylinder with cut out spirals is generated by:  
```
python3 geometry/cylinder_spiral.py
```
The resulting files are in the directory `geometry/cylinder_spiral/`.

To create a mesh of a cylinder including a coil, run the following command:  
```
python3 geometry/artificial_vessel.py
```
The resulting files are in the directory `geometry/artificial_vessel/`.


## 3. Porosity and wire direction averaging

The different workflows can be executed via

```bash
python3 permeability/main.py -c <case>
```

Available cases are:

| Case | Description |
|--------|-------------|
| `cylinder_spiral` | Generate porosity, wire direction, and permeability fields for the idealized cylinder spiral geometry. |
| `artificial_vessel` | Generate porosity, wire direction, and permeability fields for the artificial vessel geometry. |
| `real_vessel` | Generate porosity, wire direction, and permeability fields for the real aneurysm geometry. |
| `real_vessel_validation` | Compare homogenized porosity and permeability directions against the 12 reference REVs. |
| `real_perturbation_analysis` | Analyze sensitivity of reconstructed permeability tensors with respect to small orientation perturbations. |
| `rev_sensitivity` | Analyze sensitivity of porosity, direction, and permeability fields with respect to REV resolution. |
| `generate_revs` | Generate the 12 validation REVs from the real aneurysm geometry using Blender. |

For the averaging cases

```text
cylinder_spiral
artificial_vessel
real_vessel
```

the resulting fields are written to

```text
permeability/data/<case>/
```

For the validation and sensitivity cases, summary statistics are printed to the console and additional output files are written to the corresponding subdirectories of

```text
permeability/data/
```
where applicable.

## 4. Stokes flow simulations

The python code `stokes.py` soves the Stokes problem in the generated meshes.
Parameters are explained in the files and can be adapted. You can run the
simulations by the following commands:  
```
python3 stokes.py [<case>]
```
The option `<case>` decides between the generated meshes (`cube_cylinder`,
`cylinder_spiral`).

Typical runs last **up to a day** using **up to 1.2 TB of RAM** on a decent
machine. To run the examples from the article, run the script `run_stokes.py`.

## 5. Darcy flow simulations

The python code `darcy.py` uses a cube as geometry, while `darcy_cylinder.py`
and `darcy_vessel.py` use the generated meshes in `geometry/cylinder_spiral/`
and `geometry/artificial_vessel/`. Parameters are explained in the files and can
be adapted. You can run the simulations by the following commands:  
```
python3 darcy.py [-c <case>]
python3 darcy_cylinder.py [-c <case>]
python3 darcy_vessel.py [-c <case>]
```
The option `case` decides the permeability (`isotropic`, `anisotropic`, etc.).
See the respective files for the details of the other options. Note that in the
codes `darcy_cylinder.py` and `darcy_vessel.py`, the porosity is read from a VTK
file (generated in section 3).

Typical runs last **a few minutes** using **up to 32 GB of RAM** on a decent
machine. To run the examples from the article, run the scripts
`run_darcy_cube.sh` and `run_darcy_cylinder.sh` as well as
`python3 darcy_vessel.py -c anisotropic -r 0.4 -f gaussian`.


## 6. Viewing results and analysis

The output directories `<name>.pb` in the respective subdirectories of `darcy`
or `stokes` can be vizualized in e.g. `paraview` using the `ADIOS2VTXReader`.

The tables and figures presented in the article can be reproduced by running the
following commands:  
```
python3 analyze_darcy_cube.py
python3 analyze_darcy_cylinder.py --summary
```
